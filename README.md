SIGSM - Sistema de Gestión Integral de Servicios Médicos

Descripción

SIGSM (Sistema de Gestión Integral de Servicios Médicos) es un proyecto desarrollado para el Hospital de Clínicas con el objetivo de mejorar la gestión administrativa y facilitar el acceso a información relevante tanto para el personal de salud como para los pacientes.

El sistema centraliza diferentes procesos relacionados con la administración de ambulancias, gestión de documentos, encuestas de satisfacción y administración de usuarios, permitiendo una organización más eficiente de la información.

# Funcionalidades principales

Gestión de Ambulancias

* Registro de ambulancias.
* Visualización de información de traslados.
* Seguimiento de servicios médicos.
* Administración de datos relacionados con pacientes y personal asignado.

Gestión de Documentación

* Publicación de documentos institucionales.
* Consulta de documentos por parte de usuarios y visitantes.
* Organización de información por categorías.

Encuestas de Satisfacción

* Formularios de evaluación para pacientes y visitantes.
* Recolección de opiniones sobre la calidad de atención.
* Obtención de información para la mejora continua de los servicios.

Administración de Usuarios

* Registro de nuevos usuarios.
* Gestión de roles y cargos.
* Consulta de información del personal.

## Instalación

1. Clonar o descargar el repositorio.
2. Colocar el proyecto dentro de la carpeta correspondiente del servidor local.
3. Iniciar los servicios necesarios (Apache y MySQL).
4. Abrir el proyecto utilizando un navegador web.
5. Acceder a las páginas desde la carpeta `html`.

Objetivo del Proyecto

El objetivo principal de SIGSM es modernizar y optimizar la gestión de información dentro del Hospital de Clínicas mediante una solución web accesible, organizada y fácil de utilizar.

Equipo de Desarrollo

Proyecto desarrollado como parte de la formación académica en Desarrollo Web.

Repositorio

El proyecto utiliza GitHub para el control de versiones, permitiendo registrar cambios, mantener respaldo del código y facilitar el trabajo colaborativo entre los integrantes del equipo.
